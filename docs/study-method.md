# 高效学习方法指南 — 针对 CS1332x（DSA）

> 这不是一篇泛泛的"学习方法"鸡汤。它是针对**自学一门以 Java 教授的数据结构课程，同时保持 Python 工程能力，并准备 OMSCS 申请**的具体打法。

## 0 · 一个关键的认知校准

**DSA 不是看视频能学会的科目。** 你看完整门 CS1332 的视频，可能依然写不出一个红黑树。这门课的核心知识在你**手指头**上，不在你眼睛里。

经验法则：**视频时间 : 自己写代码时间 ≈ 1 : 3**。看 1 小时视频，预算 3 小时自己实现 + 调试。如果你的比例反了，回头看一下你过去三周到底有没有进步。

---

## 1 · 一周节奏（10–14 小时/周）

这是一个可以坚持几个月的节奏，不是冲刺三天的爆发。

| 周几 | 任务 | 时长 |
|------|------|------|
| 周一 | 看本周 module 的视频（1.5x 速，做 §3 的"主动笔记"） | 2 h |
| 周二 | **Java 实现**：照着课程的 API，从空文件开始写一遍数据结构 | 2 h |
| 周三 | **Java 实现** 继续 + 写 JUnit 测试覆盖边界 | 2 h |
| 周四 | **Python 复刻**：同一个数据结构用 Python 重写 + pytest | 1.5 h |
| 周五 | **LeetCode 联动**：3 道 Easy + 1 道 Medium（同主题） | 2 h |
| 周六 | edX 作业（如果有） / 修补卡壳点 | 2 h |
| 周日 | **复盘 + Obsidian 概念卡**（关键！不要跳过） | 1.5 h |

**底线**：周一缺勤就周二补；周末完全休一天可以；连续断 3 天 = 这周作废，下周从头开始（不要"赶进度"，赶不上的）。

## 2 · 三个我希望你立刻就用上的学习科学原则

### (a) 主动回忆 > 被动重读
**做**：每看完一个 lecture，**关掉视频**，拿张纸（或开个空 Markdown）写出"这一节讲了什么、API 是什么、复杂度是什么"。**不许翻看**。然后再回去对照，红笔/红色字体标出漏掉的。

**不做**：高亮笔记、抄写 PPT、第二遍重看视频。这些都是大脑骗你"我学过了"的廉价错觉。

> 模板里 `module-template.md §7` 的"主动回忆问题"就是为这个设计的。

### (b) 间隔重复
**做**：用 Anki 或 Obsidian 的间隔重复插件。每个 module 结束做 10–15 张卡片（不是复制粘贴定义 — 是问题形式，例如"为什么 ArrayList 扩容因子是 2 而不是 1.5？"）。

**节奏**：1 天后、3 天后、1 周后、3 周后、1 月后复习。

**不做**：把整段 Markdown 笔记反复读。

### (c) 刻意练习（不是"多练"，是"挑你不会的练"）
**做**：每周复盘时找出"卡壳最久的 1 个点"（笔记里有这一栏），下周一开始的 30 分钟只练它。

**不做**：刷你已经会的题刷一晚上获得多巴胺。

## 3 · "主动笔记法"（看视频时怎么做笔记）

**绝对不要**：边看边把字幕复制下来 / 截图 PPT。

**应该做**：暂停。每听完一个完整的概念（通常 3–5 分钟），暂停视频，用**自己的话**写下：

```
概念: ____
为什么需要它（它解决了原先什么问题）: ____
最简单的例子: ____
一句话不能讲清楚的"细节坑": ____
```

如果某一格写不出来 → 倒回去再看一次。如果还是写不出来 → 标记 ❓，今天先过，周日复盘时再回来。

这种笔记**慢 3 倍**，但**留存高 10 倍**。一节视频 20 分钟你可能花 60 分钟做完，这是正常的，不是低效。

## 4 · "Java 学课 + Python 复刻"双轨编程的具体打法

CS1332 教 Java 不是巧合 — Java 的强类型 + 明确泛型让数据结构的契约比 Python 清楚得多。所以**不要尝试"省略 Java，直接用 Python"**。

但是你日常用 Python，光学 Java 又会让肌肉记忆掉链子。解法是**双轨**：

### Java 优先（学懂结构）

每个数据结构按这个顺序：
1. 看课程视频 + 写课程要求的 API
2. 用 JUnit 写 ≥ 10 个测试（含边界：空、单元素、容量边界、null 输入）
3. 跑 `mvn test` 全绿才算"过"

### Python 复刻（保留语言肌肉）

24–48 小时内（关键 — 趁热打铁）：
1. **不看 Java 代码**，凭记忆用 Python 实现同一个 API
2. 用 `pytest` 跑同样的边界用例
3. 写一段 30 行的对照笔记：**两种语言里这个数据结构的体现有什么不同？**（例如 Python `list` 已经是动态数组，所以"实现 ArrayList"在 Python 里要刻意不用内置方法）

### 为什么这有效
- Java 强迫你想清楚泛型、null 处理、可见性 → 训练**工程纪律**
- Python 复刻 = 不看答案的考试 → 暴露你"看懂"和"会做"的差距
- 申请 OMSCS 时，GitHub 上同一个数据结构两个语言实现 + 测试 = **极少有申请者做到这一点**

## 5 · LeetCode 联动节奏

不要等课程结束再刷题 — 那时你已经忘了。

**规则**：每个 module 结束当晚刷 3–5 道**主题对口**的题（不是随机刷）。

| Module | LeetCode 对口题（建议起点） |
|--------|----------------------------|
| Arrays | 26, 27, 88, 283, 977 |
| LinkedList | 206, 21, 141, 142, 19 |
| Stacks & Queues | 20, 155, 232, 739 |
| Trees | 104, 226, 110, 98, 102 |
| Heaps | 215, 703, 347, 23 |
| HashMap | 1, 49, 128, 560 |
| Sorting | 912, 75, 148 |
| Graphs | 200, 207, 994, 743 |
| DP | 70, 198, 322, 300 |

**刷题原则**：
- 先想 15 分钟。想不出来看 hint，不看答案。
- 看完答案后**关掉**，自己从头写一遍。
- 解出来之后写一段 5 行的"我学到的模式"，存到 `practice/leetcode/<题号>-<slug>.py` 文件头注释里。

## 6 · 防止"自学崩塌"的三个具体技巧

自学最大的敌人不是"难"，是"没人在乎"。

### (a) 公开承诺
GitHub repo 设为 public。每周日发一条 commit 信息形如 `weekly: completed module 03 (stacks & queues)`. 哪怕没人看 — 知道**理论上**有人能看，就是动力。

### (b) 时间盒，不是任务盒
不要计划"今晚学完 module 04"。计划"今晚 7:30–9:30 学 module 04"。前者会让你 11 点还在自责，后者让你 9:30 关电脑去睡觉。

### (c) 卡壳上限 = 45 分钟
任何一个点卡了 45 分钟以上 → 标 ❓ 跳过，写进 §8 的"待问列表"。第二天用新的脑子，或者去 r/learnprogramming / Stack Overflow / Discord 问。**死磕一晚上 = 第二天什么都不想学**。

## 7 · 月度回看（每 4 周一次）

每月一次，做这件事：
1. 把 `notes/weekly/` 下四周的复盘看一遍
2. 更新 Obsidian 的 `CS1332-MOC.md`，把新概念串起来
3. 录一段 **3 分钟视频**给自己听：用本月学的所有概念解决一个具体问题（例如"用我学过的数据结构设计一个浏览器历史记录功能"）
4. 把视频文件名加到 monthly retrospective，**不要上传** — 这是你自己看的

如果某次录视频感觉"讲不出来" → 这是诚实的信号，回去补这一个月。

## 8 · 申请 OMSCS 的硬指标对齐

CS1332 之外，OMSCS 招生官也想看：
- **持续性**：你能不能坚持？→ 你的 GitHub commit graph 是答案
- **诚信**：不抄答案 → 这就是为什么 `.gitignore` 里排除了 `solution.*`
- **沟通**：能不能讲清楚？→ 你的 README 和 weekly review 就是证据

CS1332 拿到证书（edX paid track）+ 一份漂亮的 GitHub repo + 一封从这段经历里抽出的 SOP 故事 = 一个很强的申请片段。

## 9 · 推荐配套资源（用，但不要囤）

**只选 1–2 本配读**，不要囤资源（囤书是自欺）：
- Sedgewick & Wayne, *Algorithms* 4th ed.（Java，CS1332 风格最一致）
- CLRS *Introduction to Algorithms*（参考书，不要从头读，遇到再查）
- VisuAlgo（visualgo.net）— 看动画理解数据结构操作

刷题：LeetCode + NeetCode 150（NeetCode 的 YouTube 题解质量高）。

## 10 · 一句话总结

> 数据结构课只有两个真问题：**(1) 你能不能不看任何参考、从空文件写出一个 AVL 树？(2) 你能不能用大白话向你妈解释什么是哈希冲突？** 

如果两个都行，证书只是顺便。如果两个都不行，看再多视频也没用。

每周日复盘时，问自己这两个问题一次。
